# Personal Portfolio

My personal portfolio website showcasing my projects, experience, achievements, and technical skills.

🌐 Live website: https://jamaltey.github.io

## About

This portfolio contains selected projects, technical experience, and achievements in software engineering and web development. It was built to showcase my work and provide a central place for future employers, collaborators, and university admissions officers to learn more about my technical background.

## Features

- Responsive design
- Project showcase
- Experience & achievements
- Resume
- Contact information

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router

## Getting Started

Clone the repository:

```bash
git clone https://github.com/jamaltey/jamaltey.github.io.git
cd jamaltey.github.io
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
